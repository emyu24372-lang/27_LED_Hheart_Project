<img width="4096" height="3072" alt="tutuu" src="https://github.com/user-attachments/assets/3057361e-90fb-48be-b869-43b63e830b94" />This project consists of 27 LEDs controlled by an ESP32 Mini. It has three modes that can be switched between by pressing a button.
The first mode turns all the LEDs on. In the second mode
each LED turns on and off one by one. In the final mode
all the LEDs pulse together like a beating heart.
